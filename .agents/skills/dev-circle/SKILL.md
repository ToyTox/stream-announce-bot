# Запуск цикла разработки

Это псевдоним скила `dev-cycle`.

1. Прочитай [канонические инструкции процесса](../dev-cycle/SKILL.md) и следуй им для текущей задачи. Все этапы, ограничения и исключения определяются этим файлом.
2. Описание после `/dev-circle` или `$dev-circle` считай постановкой задачи. Если описания нет и задача не определена в текущем чате, уточни, что требуется сделать.
