# Мобильное приложение

Самостоятельный каркас на React Native, Expo SDK 58 и TypeScript. Основная платформа — Android; iOS пока без проверки на устройстве. У приложения собственные зависимости и lock-файл; корневые команды относятся к боту и настольному приложению.

При запуске открывается «Сопряжение». Вкладки «Статус», «Сообщение», «Настройки» и «Лог» доступны без подключения. Выбранный раздел выделяется, системная кнопка возврата на Android открывает предыдущую посещённую вкладку; когда история исчерпана, возврат передаётся системе. Светлая и тёмная темы следуют системе, меняются без перезапуска и сохраняют выбранный экран. Если тема системы неизвестна, используется светлая.

## Установка и запуск

Нужен Node.js 22.13 или новее в ветке 22, либо совместимая версия из `engines` в `package.json`. Команды выполняются из корня репозитория:

```sh
npm --prefix mobile ci
npm --prefix mobile start
```

Установите совместимый с SDK 58 клиент Expo Go на тестовый телефон и откройте показанный код. Телефон и компьютер должны иметь доступ друг к другу по локальной сети. Для уже запущенного Android-эмулятора или подключённого телефона с настройкой отладки используйте `npm --prefix mobile run android`; для запущенного симулятора iOS на Mac — `npm --prefix mobile run ios`. Эти команды запускают сервер разработки и открывают клиент, установщик не собирается. Сам бот для проверки каркаса не нужен.

## Проверки

```sh
npm --prefix mobile run typecheck
npm --prefix mobile test -- --runInBand
cd mobile
CI=1 npx expo install --check
npx expo export --platform android
```

Последняя команда создаёт пакет JavaScript и ресурсов в `mobile/dist/`, без нативного проекта и установщика. Тесты используют настоящую навигацию и подменяют системные интерфейсы окружения: тема, кнопка возврата, безопасные области. Проверяются все пять заглушок, переходы и возврат, начальные темы и смена темы без потери текущего раздела. Настройки Jest ограничены `mobile/tests/`; корневые тесты запускаются отдельно через `npm test`.

Для ручной проверки откройте каждый раздел, пройдите назад системной кнопкой до стартового экрана, переключите системную тему при открытом приложении. Проверьте читаемость, выбранную вкладку и отступы от вырезов, статусной панели и нижней системной панели в обоих оформлениях, включая увеличенный размер текста. На устройстве эти проверки пока не выполнены.

## Структура

| Путь | Назначение |
|------|------------|
| `index.ts`, `App.tsx` | Регистрация приложения, системные панели, тема и безопасная область |
| `src/navigation.tsx` | Пять вкладок и история возврата |
| `src/screens.tsx` | Названия разделов и заглушки |
| `src/theme.ts` | Палитры и подписка на тему системы |
| `tests/` | Проверки интерфейса и системных изменений |
| `app.json`, `tsconfig.json`, `jest.config.cjs` | Настройки приложения, типов и тестов |

## Ограничения

Это пункт 11 [мобильного плана](../docs/mobile-app-plan.md). Клиента API, токенов, сопряжения, сканера, рабочих действий, фото и уведомлений пока нет. Приложение не обращается к боту, не запрашивает разрешений устройства и не показывает успешное подключение или отправку. Сетевое подключение нужно только для получения пакета от сервера разработки. Поддержка системной темы Android настроена через `userInterfaceStyle: automatic` и `expo-system-ui`; цвета системных панелей согласованы с темой, содержимое учитывает безопасную область. Распространение и нативные сборки относятся к последующим задачам.

Контракты: [навигация](https://docs.expo.dev/develop/app-navigation/), [системная тема](https://docs.expo.dev/develop/user-interface/color-themes/), [тестирование](https://docs.expo.dev/develop/unit-testing/), [команды](https://docs.expo.dev/more/expo-cli/).
