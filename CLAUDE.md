# stream-announce-bot

Любая задача на изменение кода, тестов или документации выполняется через скил `dev-cycle` (`.claude/skills/dev-cycle/SKILL.md`): план → утверждение → реализация по плану → независимое ревью → повтор при замечаниях → текст коммита, описания PR и, если изменения дойдут до пользователей приложения, версия и описание релиза (коммитит, оформляет PR и выпускает релиз пользователь сам). Вопросы, не требующие изменений, можно отвечать напрямую.
