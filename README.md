# stream-announce-bot

Бот следит за Twitch, YouTube и VK Live и, когда вы начинаете стрим, отправляет в Telegram-группу один анонс со ссылками на все площадки, где идёт эфир. OBS запускает трансляцию везде одновременно, поэтому вместо нескольких уведомлений получается одно сообщение. Когда эфир заканчивается, бот отправляет отдельное сообщение с длительностью и ссылками на записи.

Управлять ботом можно из локальной веб-панели в браузере или командами в личке Telegram.

## Стек

- **Node.js 22** с TypeScript (ESM)
- **axios** — HTTP-запросы к площадкам и Telegram
- **better-sqlite3** — локальная база состояния
- **Electron** — необязательное десктопное приложение
- **node:http** — веб-панель, без фреймворков и сборки фронтенда
- **vitest** — тесты

## Установка

```bash
npm install
cp .env.example .env
```

Заполните `.env` (см. «Настройка бота» ниже) или запустите бота и заполните настройки в веб-панели.

## Запуск

### Рабочий режим — бот анонсирует стримы

```bash
npm run build
npm start
```

Запускает собранный JavaScript из `dist/` вместе с веб-панелью. Бот работает, пока открыт терминал, и не перезапускается от правок файлов.

После изменения кода (в том числе после `git pull`) остановите бота (Ctrl+C) и повторите `npm run build` и `npm start`. Состояние эфира хранится в базе, поэтому перезапуск посреди стрима не приведёт к повторному анонсу.

### Режим разработки — правка кода

```bash
npm run dev
```

Запускает TypeScript напрямую и перезапускает бота при каждом сохранении файла в `src/`. Сборка не нужна.

Чтобы во время разработки не отправлять сообщения в группу, поставьте `DRY_RUN=true` — анонсы будут только печататься в терминал — или укажите в `TELEGRAM_CHAT_ID` свой user ID, чтобы они приходили вам в личку.

### Что выбрать

| Задача | Команда |
|--------|---------|
| Бот работает и анонсирует ваши стримы | `npm run build` + `npm start` |
| Меняете код или шаблон сообщений | `npm run dev` |
| Бот в фоне с иконкой в строке меню | `npm run desktop` |

Не запускайте два экземпляра одновременно: они работают с одной базой и одним токеном, поэтому могут отправить анонс дважды и перехватывать друг у друга команды.

### Работа на Mac без сна

Если бот крутится на MacBook, который работает с закрытой крышкой, запретите сон:

```bash
sudo pmset -a disablesleep 1   # вернуть: sudo pmset -a disablesleep 0
```

Блокировка экрана и выключенный дисплей боту не мешают — останавливает его только сон системы. С этой настройкой не убирайте MacBook в сумку: он не уснёт и будет разряжаться.

## Десктопное приложение

«Анонсы стримов» — Electron-оболочка: бот работает в фоне, в строке меню (трее) висит иконка со статусом, а окно показывает ту же веб-панель.

```bash
npm install
npm run desktop
```

Команда собирает приложение в `dist-desktop/` и запускает его. При первом запуске (или если настройки с ошибкой) окно открывается на вкладке «Настройки»; дальше приложение живёт в трее, а окно открывается по пункту «Открыть панель».

**Меню в трее**

| Пункт | Что делает |
|-------|-----------|
| Статус (неактивная строка) | «Эфира нет», «● Эфир идёт с 18:00 · Twitch, YouTube», «Тестовый режим» или «Бот не запущен: <ошибка>» |
| Открыть панель | Показывает окно |
| Проверить сейчас | Внеочередная проверка площадок |
| Запускать при входе в систему | Автозапуск приложения (запускается скрыто, в трее) |
| Не давать системе засыпать | Пока включено, система не уходит в сон из-за бездействия; на закрытую крышку не влияет |
| Выйти | Останавливает бота и закрывает приложение |

Иконка меняется: кольцо — эфира нет, закрашенный круг — эфир идёт, с «!» — тестовый режим или ошибка проверки площадки, перечёркнутое — бот не запущен. Закрытие окна крестиком только прячет его (на macOS пропадает и значок в Dock): бот продолжает работать. Уведомления приходят, когда анонс отправлен, эфир завершён или анонс не удалось отправить.

**Где лежат данные.** `.env` и база `bot.db` — в папке приложения: `~/Library/Application Support/Анонсы стримов/` (на Windows `%APPDATA%`, на Linux `~/.config`). Файл `.env` в корне проекта приложение не читает. Если `DATABASE_PATH` не задан, база создаётся рядом с `.env`.

**Перенос настроек.** Во вкладке «Настройки» кнопка «Импортировать .env…» заменяет настройки приложения выбранным файлом: он проверяется, и если в нём ошибка, ничего не меняется. Так можно перенести настройки из терминального режима.

**Одна копия.** Повторный запуск не создаёт второго бота, а показывает окно уже работающего.

**Не запускайте вместе с `npm start`.** У приложения своя база: два бота с одним токеном не знают друг о друге и отправят анонс дважды. Выберите один способ запуска.

**Закрытая крышка MacBook.** Пункт «Не давать системе засыпать» не мешает сну при закрытой крышке — для этого по-прежнему нужен `sudo pmset -a disablesleep 1` (см. «Работа на Mac без сна»).

**Нативный модуль.** better-sqlite3 с версии 13 собран на Node-API, поэтому один и тот же бинарник работает и в Node (`npm test`, `npm start`), и в Electron — пересборка под Electron не нужна. Если на вашей платформе загрузился неподходящий бинарник, пересоберите модуль: `npx electron-rebuild -f -w better-sqlite3` (для Electron) или `npm rebuild better-sqlite3` (для Node). Скрипт `scripts/desktop.mjs` запускает Electron без переменной `ELECTRON_RUN_AS_NODE`, которую выставляет терминал VS Code.

Для проверок можно задать отдельную папку данных: `STREAM_BOT_USER_DATA=/tmp/bot-test npm run desktop`.

## Панель управления

Вместе с ботом запускается панель — откройте **http://localhost:3210**. Ссылка также печатается в терминале при запуске.

| Вкладка | Что там |
|---------|---------|
| Статус | Идёт ли эфир, отправлен ли анонс (со ссылкой на сообщение), состояние каждой площадки и ошибки проверки. Кнопки «Проверить сейчас» и «Тестовое сообщение в группу» |
| Сообщение | Текст в анонс (как `/text`, переносы строк сохраняются), своё превью — загрузка картинки с компьютера, предпросмотр анонса и сообщения об окончании |
| Настройки | Все параметры `.env` формой. Секреты показываются замаскированными, пустое поле — не менять. Сохранение проверяет значения, пишет `.env` (комментарии сохраняются) и перезапускает бота без повторного анонса. Кнопка «Импортировать .env…» заменяет настройки целым файлом |
| Лог | Последние 300 строк того, что бот пишет в терминал |

- Панель слушает только `127.0.0.1`: из сети и с телефона она недоступна, запросы с чужих сайтов отклоняются. Пароля нет — всё, что видно в панели, и так лежит в `.env` на этом компьютере.
- Загрузка картинки требует `TELEGRAM_ADMIN_ID`: бот отправляет её вам в личку, чтобы Telegram сохранил файл, и дальше использует его в анонсах.
- Если `.env` заполнен с ошибкой, бот не запустится, но панель поднимется и покажет ошибку — её можно исправить во вкладке «Настройки».
- Порт меняется через `WEB_PORT`, выключить панель — `WEB_ENABLED=false`. В десктопном приложении панель работает всегда, а если порт занят, берётся свободный.

## Настройка бота

1. **Бот в Telegram**: напишите `@BotFather` команду `/newbot` и получите токен — это `TELEGRAM_BOT_TOKEN`.
2. **Группа**: добавьте бота в группу. Права администратора не обязательны, если в группе не запрещено писать участникам.
3. **ID группы** (`TELEGRAM_CHAT_ID`): скопируйте ссылку на любое сообщение группы — `t.me/c/2241331974/…` — и добавьте `-100` перед числом: `-1002241331974`.
4. **Тема** (`TELEGRAM_TOPIC_ID`): если в группе включены темы, ID темы — первое число после ID группы в ссылке на сообщение из неё. Для основной темы (General, даже переименованной) оставьте поле пустым.
5. **Ваш user ID** (`TELEGRAM_ADMIN_ID`): напишите `@userinfobot`, он ответит вашим ID. Затем отправьте своему боту `/start` — без этого он не сможет писать вам в личку.
6. **Twitch**: создайте приложение на [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) (Redirect URL — `https://localhost`, тип клиента — «Конфиденциально») и возьмите Client ID и Client Secret. Логин — как в адресе `twitch.tv/<логин>`.
7. **YouTube**: ID канала вида `UC…` — на [youtube.com/account_advanced](https://www.youtube.com/account_advanced). Ник `@…` не подходит.
8. **VK Live**: имя канала из адреса `live.vkvideo.ru/<имя>`. Для ссылки на записи укажите в `VKVIDEO_REPLAY_URL` канал на vkvideo.ru.
9. **Проверка**: запустите бота и во вкладке «Статус» панели нажмите «Тестовое сообщение в группу».

## Переменные `.env`

| Переменная | Обязательна | Что задаёт |
|------------|-------------|------------|
| `TELEGRAM_BOT_TOKEN` | да | Токен бота |
| `TELEGRAM_CHAT_ID` | да | Группа для анонсов |
| `TELEGRAM_TOPIC_ID` | | Тема форума; пусто — основная |
| `TELEGRAM_ADMIN_ID` | | Ваш user ID: команды в личке и загрузка превью из панели |
| `TWITCH_LOGIN`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET` | | Twitch — все три вместе |
| `YOUTUBE_CHANNEL_ID` | | YouTube |
| `YOUTUBE_API_KEY` | | Проверять YouTube через Data API, а не страницу `/live` |
| `VKVIDEO_CHANNEL` | | VK Live |
| `VKVIDEO_REPLAY_URL` | | Ссылка на канал VK Video с записями |
| `PRIMARY_PLATFORM` | | Откуда брать название, игру и превью (`twitch`) |
| `POLL_INTERVAL_MS` | | Интервал опроса площадок (`60000`) |
| `ANNOUNCE_GRACE_MS` | | Пауза перед анонсом (`90000`) |
| `OFFLINE_GRACE_MS` | | Сколько молчания считать концом эфира (`180000`) |
| `ANNOUNCE_END` | | Сообщение об окончании эфира (`true`) |
| `DRY_RUN` | | Ничего не отправлять, только печатать (`false`) |
| `DATABASE_PATH` | | Файл базы (`./data/bot.db`) |
| `WEB_ENABLED`, `WEB_PORT` | | Панель управления (`true`, `3210`) |

Нужна хотя бы одна площадка. В скобках — значения по умолчанию.

## Команды бота

Пишите боту в личку. Он отвечает только на сообщения от `TELEGRAM_ADMIN_ID`; без этой настройки команды выключены.

| Команда | Описание |
|---------|----------|
| `/text <текст>` | Текст в ближайший анонс; после отправки сбрасывается |
| `/text` | Показать текущий текст |
| `/text -` | Сбросить текст |
| *фото* | Своё превью для всех анонсов — до замены другим фото или сброса. Отправлять как фото, со сжатием |
| `/image` | Задано ли своё превью |
| `/image -` или `/image_clear` | Сбросить своё превью |
| `/status` | Идёт ли эфир, на каких площадках и с какого времени |
| `/help` | Справка по командам |

## Поведение

- **Первая замеченная площадка** открывает эфир, но анонс уходит не сразу: бот ждёт 90 секунд (`ANNOUNCE_GRACE_MS`), пока подключатся остальные площадки из OBS.
- **Одно сообщение** со ссылками на все площадки, которые в эфире на момент отправки.
- **Название и игра** берутся только с Twitch (`PRIMARY_PLATFORM`): на других площадках они могут отличаться. Если Twitch не в эфире, название будет «Трансляция».
- **Превью**: своё (из лички или панели), если задано, иначе превью Twitch. Если нет ни того, ни другого, анонс уходит текстом.
- **Анонс не редактируется**: если площадка потом упала, ссылка остаётся; если подключилась позже — в анонс не попадает.
- **Окончание**: эфир закрывается, если все площадки молчат дольше 3 минут (`OFFLINE_GRACE_MS`) — это защита от разрывов. После этого уходит отдельное сообщение с длительностью и ссылками на каналы с записями. Выключается `ANNOUNCE_END=false`.
- **Ошибка проверки** площадки (сеть, сбой API) не закрывает эфир — закрывает только явный ответ «офлайн».
- **Перезапуск** посреди эфира, в том числе из панели, не приводит к повторному анонсу.

## Как выглядят сообщения

**Анонс** — фото с подписью:

```
Всем привет

🔴 <название стрима на Twitch>
🎮 <игра на Twitch>

<текст из /text или панели>

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

**Окончание эфира** — отдельное текстовое сообщение:

```
⚫️ <название стрима на Twitch>
🎮 <игра на Twitch>

Эфир завершён, длился 2 ч 47 мин

Всем спасибо, кто забегал на стрим, повтор стрима можно посмотреть тут:

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

Название площадки — кликабельная ссылка. В анонсе — площадки, которые были в эфире в момент отправки (VK Video идёт вместе с VK Live), в итоге — все настроенные каналы. Строки 🎮 нет, если на Twitch не выбрана категория; строки с текстом — если он не задан.
