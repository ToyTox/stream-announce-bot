# stream-announce-bot

[English](README.en.md) · **Русский**

Бот следит за Twitch, YouTube и VK Live и, когда вы начинаете стрим, отправляет в Telegram-группу (и, если настроен вебхук, в канал Discord) один анонс со ссылками на все площадки, где идёт эфир. OBS запускает трансляцию везде одновременно, поэтому вместо нескольких уведомлений получается одно сообщение. Когда эфир заканчивается, бот отправляет отдельное сообщение с длительностью и ссылками на записи.

Управлять ботом можно из окна приложения или командами в личке Telegram. Команд в Discord нет: он только принимает сообщения. Telegram необязателен, если задан вебхук Discord: тогда бот анонсирует только в Discord, а управление идёт через панель.

## Скачать и установить

Скачайте установщик со страницы [Releases](https://github.com/ToyTox/stream-announce-bot/releases) — собирать ничего не нужно.

**Mac**

1. Скачайте `stream-announce-<версия>-arm64.dmg` для Mac на Apple Silicon (M1 и новее) или `stream-announce-<версия>-x64.dmg` для Intel. Узнать свой процессор: меню  → «Об этом Mac».
2. Откройте `.dmg` и перетащите приложение в «Программы».
3. Приложение подписано бесплатной подписью без сертификата разработчика, поэтому при первом запуске macOS скажет, что не может проверить его. Закройте окно, откройте «Системные настройки → Конфиденциальность и безопасность», прокрутите вниз до сообщения о приложении и нажмите «Всё равно открыть». Это нужно один раз.

**Windows**

1. Скачайте `stream-announce-<версия>-x64.exe` и запустите. Установщик запросит права администратора и поставит приложение в `Program Files`; папку можно сменить. Ярлыки появятся на рабочем столе и в меню «Пуск».
2. SmartScreen может написать «Система Windows защитила ваш компьютер»: нажмите «Подробнее → Выполнить в любом случае».

При первом запуске окно откроется на вкладке «Настройки». Дальше приложение живёт в фоне: иконка в строке меню (на Windows — в трее) показывает статус, а окно открывается по пункту «Открыть панель». Закрытие окна крестиком бота не останавливает; чтобы выйти, выберите «Выйти» в меню иконки.

## Настройка бота

Блок Telegram (шаги 1–5) необязателен, если задан `DISCORD_WEBHOOK_URL` (шаг 9). Telegram включается, когда заданы и `TELEGRAM_BOT_TOKEN`, и `TELEGRAM_CHAT_ID`; одно из двух — ошибка. Нужна хотя бы одна площадка доставки: Telegram или Discord.

1. **Бот в Telegram**: напишите `@BotFather` команду `/newbot` и получите токен — это `TELEGRAM_BOT_TOKEN`.
2. **Группа**: добавьте бота в группу. Права администратора не обязательны, если в группе не запрещено писать участникам.
3. **ID группы** (`TELEGRAM_CHAT_ID`): скопируйте ссылку на любое сообщение группы — `t.me/c/2241331974/…` — и добавьте `-100` перед числом: `-1002241331974`.
4. **Тема** (`TELEGRAM_TOPIC_ID`): если в группе включены темы, ID темы — первое число после ID группы в ссылке на сообщение из неё. Для основной темы (General, даже переименованной) оставьте поле пустым.
5. **Ваш user ID** (`TELEGRAM_ADMIN_ID`): напишите `@userinfobot`, он ответит вашим ID. Затем отправьте своему боту `/start` — без этого он не сможет писать вам в личку.
6. **Twitch**: создайте приложение на [dev.twitch.tv/console/apps](https://dev.twitch.tv/console/apps) (Redirect URL — `https://localhost`, тип клиента — «Конфиденциально») и возьмите Client ID и Client Secret. Логин — как в адресе `twitch.tv/<логин>`.
7. **YouTube**: ID канала вида `UC…` — на [youtube.com/account_advanced](https://www.youtube.com/account_advanced). Ник `@…` не подходит.
8. **VK Live**: имя канала из адреса `live.vkvideo.ru/<имя>`. Для ссылки на записи укажите в `VKVIDEO_REPLAY_URL` канал на vkvideo.ru.
9. **Discord** (необязательно, если настроен Telegram): Настройки сервера → Интеграции → Вебхуки → Новый вебхук → выберите канал → «Копировать URL вебхука». Адрес вида `https://discord.com/api/webhooks/<id>/<токен>` — это `DISCORD_WEBHOOK_URL`. В адресе есть токен: никому его не показывайте.
10. **Проверка**: во вкладке «Статус» нажмите «Проверка связи»: тест уйдёт в каждую настроенную площадку, результат показан по каждой.

Значения вводятся во вкладке «Настройки» панели; нужна хотя бы одна площадка. Там же у каждой группы есть свёрнутая инструкция «Как получить».

## Панель управления

| Вкладка | Что там |
|---------|---------|
| Статус | Идёт ли эфир, отправлен ли анонс (со ссылкой на сообщение), состояние каждой площадки и ошибки проверки. Кнопки «Проверить сейчас», «Проверка связи», «Тестовый анонс в Telegram» и «Тестовый анонс в Discord» (настоящий анонс с пометкой «🧪 Тест» только в выбранную площадку; в Telegram — без звука); кнопки площадок, которые не настроены, скрыты |
| Сообщение | Текст в анонс (как `/text`), свой список ссылок (в том числе на площадки, которые бот не отслеживает; отмеченные «всегда в анонсе» заменяют ссылки на запущенные площадки), своё превью — загрузка картинки с компьютера, предпросмотр анонса и сообщения об окончании |
| Настройки | Все параметры формой. Секреты показываются замаскированными, пустое поле — не менять. Сохранение проверяет значения и перезапускает бота без повторного анонса. Кнопка «Импортировать .env…» заменяет настройки целым файлом |
| Лог | Последние 300 строк того, что бот пишет |

- Панель доступна только на этом компьютере, пароля нет.
- Своя картинка хранится в папке данных рядом с базой: из неё она уходит в Discord. С Telegram и `TELEGRAM_ADMIN_ID` бот ещё отправляет её вам в личку, чтобы Telegram сохранил file_id. Без Telegram или без `TELEGRAM_ADMIN_ID` картинка загружается из панели и хранится только локально (в Telegram, если он включён, уходит файлом).
- Без Telegram недоступны команды бота и сообщения админу; всё остальное, включая текст в анонс и картинку, делается в панели.
- Если настройки заполнены с ошибкой, бот не запустится, но панель покажет ошибку — её можно исправить во вкладке «Настройки».

## Команды бота

Пишите боту в личку. Он отвечает только на сообщения от `TELEGRAM_ADMIN_ID`; без этой настройки команды выключены.

| Команда | Описание |
|---------|----------|
| `/text <текст>` | Текст в ближайший анонс; после отправки сбрасывается |
| `/text` | Показать текущий текст |
| `/text -` | Сбросить текст |
| *фото* | Своё превью для всех анонсов — до замены другим фото или сброса. Отправлять как фото, со сжатием |
| `/image` | Задано ли своё превью |
| `/image -` или `/image_clear` | Сбросить своё превью |
| `/status` | Идёт ли эфир, на каких площадках и с какого времени |
| `/help` | Справка по командам |

## Язык

Интерфейс и тексты анонсов бывают на русском и английском, настраиваются отдельно. Язык интерфейса переключается в шапке панели или полем «Язык интерфейса» во вкладке «Настройки»; язык анонса — полем «Язык текстов анонса» там же. Если оставить пустыми, интерфейс выберется по языку системы, а анонс будет на языке интерфейса. Команды бота на всех языках одинаковые.

## Как выглядят сообщения

**Анонс** — фото с подписью:

```
Всем привет

🔴 <название стрима на Twitch>
🎮 <игра на Twitch>

<текст из /text или панели>

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

**Окончание эфира** — отдельное текстовое сообщение:

```
⚫️ <название стрима на Twitch>
🎮 <игра на Twitch>

Эфир завершён, длился 2 ч 47 мин

Всем спасибо, кто забегал на стрим, повтор стрима можно посмотреть тут:

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

Название площадки — кликабельная ссылка. В Discord состав тот же, но это карточка. В анонсе — площадки, которые были в эфире в момент отправки, в итоге — все настроенные каналы. Строки 🎮 нет, если на Twitch не выбрана категория; строки с текстом — если он не задан. Анонс уходит не сразу, а через 90 секунд после первой площадки, чтобы дождаться остальных. Название и игра берутся с Twitch, превью — своё (если задано) или с Twitch. В Discord уходит та же картинка: своя, иначе превью Twitch, иначе только текст. Подробные правила — в [документе для разработчиков](docs/development.md).

## Обновление и данные

Приложение раз в сутки проверяет последний релиз на GitHub; если есть новее, в меню иконки появляется «Доступна версия X — скачать». Скачайте новый установщик и установите поверх: настройки и база сохраняются. Текущая версия видна в меню иконки и в шапке панели.

Данные лежат в `~/Library/Application Support/Анонсы стримов/` на Mac и `%APPDATA%\Анонсы стримов\` на Windows: файлы `.env` и `bot.db`. На Windows они хранятся отдельно для каждого пользователя, поэтому запускайте бота под одной учётной записью.

**Запускайте бота только в одном месте — на Mac или на Windows.** Две копии с одним токеном Telegram отправят анонс дважды и будут перехватывать друг у друга команды.
