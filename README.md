# stream-announce-bot

Бот автоматически опрашивает Twitch, YouTube и VK Video и отправляет в Telegram-группу одно сообщение, когда вы начинаете стрим. Все платформы стартуют из OBS одновременно, поэтому вместо трёх раздельных уведомлений — один анонс со ссылками на все живые площадки.

## Стек

- **Node.js 22** с TypeScript (ESM)
- **axios** — HTTP-запросы к платформам
- **better-sqlite3** — локальная база данных состояния
- **vitest** — тесты

## Установка

```bash
npm install
cp .env.example .env
# Заполнить токены в .env (см. «Настройка бота» ниже)
```

## Запуск

### Рабочий режим — бот анонсирует стримы

```bash
npm run build
npm start
```

Запускает собранный JavaScript из `dist/`. Бот работает, пока открыт терминал, и не реагирует на правки файлов — случайное сохранение в редакторе его не перезапустит.

После любого изменения кода (в том числе после `git pull`) остановите бота (Ctrl+C) и повторите `npm run build` и `npm start`. Состояние эфира хранится в базе, поэтому перезапуск посреди стрима не приведёт к повторному анонсу.

### Режим разработки — правка кода

```bash
npm run dev
```

Запускает TypeScript напрямую и перезапускает бота при каждом сохранении файла в `src/`. Сборка не нужна, правки видны сразу.

Чтобы во время разработки не отправлять сообщения в группу, поставьте в `.env` `DRY_RUN=true` — анонсы будут только печататься в терминал — или укажите в `TELEGRAM_CHAT_ID` свой user ID, чтобы они приходили вам в личку.

### Что выбрать

| Задача | Команда |
|--------|---------|
| Бот работает и анонсирует ваши стримы | `npm run build` + `npm start` |
| Меняете код, шаблон сообщений, проверяете правки | `npm run dev` |

Не запускайте оба режима одновременно: два экземпляра с одним токеном будут мешать друг другу получать команды и могут отправить анонс дважды.

## Скрипты

| Команда | Что делает |
|---------|-----------|
| `npm run build` | Сборка TypeScript в `dist/` |
| `npm start` | Рабочий запуск собранного проекта (сначала `npm run build`) |
| `npm run dev` | Запуск для разработки: перезапуск при сохранении файлов |
| `npm test` | Запуск тестов |
| `npm run typecheck` | Проверка типов без сборки |

## Настройка бота

1. **Создать бота в Telegram**: напишите `@BotFather` команду `/newbot` и получите токен.
2. **Добавить в группу и дать права**: добавьте бота в приватную группу и **дайте ему права администратора**.
3. **Проверить доступ**: выполните `curl "https://api.telegram.org/bot<TOKEN>/sendMessage?chat_id=-1002241331974&text=test"` — если `chat not found`, бот не в группе.
4. **Получить ваш user ID**: напишите боту в личку, затем `curl "https://api.telegram.org/bot<TOKEN>/getUpdates"`.
5. **Twitch**: создайте приложение на `dev.twitch.tv/console/apps` и получите `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.
6. **Остальные платформы**: укажите логин Twitch, ID канала YouTube (вида `UC…`) и канал VK Video.

## Команды бота

Команды пишите боту в личку (если он добавлен в ваши контакты):

| Команда | Описание |
|---------|----------|
| `/text <текст>` | Добавить врезку в следующий анонс |
| `/text` | Показать текущую врезку |
| `/text -` | Отмена врезки |
| *фото* | Превью для всех анонсов вместо превью Twitch — до замены другим фото или `/image -` (отправить как фото, со сжатием) |
| `/image` | Задано ли своё превью |
| `/image -` или `/image_clear` | Сбросить своё превью |
| `/status` | Какие платформы сейчас в эфире и когда начался |
| `/help` | Справка по командам |

## Поведение

- **Первая замеченная платформа** открывает эфир, но сообщение не отправляется сразу.
- **Ждём 90 секунд** (`ANNOUNCE_GRACE_MS`), чтобы подключились другие платформы, запущенные из OBS одновременно.
- **Одно сообщение** со ссылками на все живые платформы.
- **Название, игра и превью** берутся только с Twitch (`PRIMARY_PLATFORM`): у других площадок названия могут отличаться. Если Twitch не в эфире, анонс уходит текстом без превью и с названием «Трансляция».
- **Анонс не редактируется**: ссылки фиксируются в момент отправки. Если площадка потом упала, ссылка остаётся; если подключилась позже — в анонс не попадает.
- **Окончание**: эфир закрывается, если все платформы молчат дольше **3 минут** (защита от разрывов соединения). После этого уходит **отдельное сообщение** с длительностью эфира и ссылками на каналы, где лежит запись (Twitch, YouTube, VK Video из `VKVIDEO_REPLAY_URL`, VK Live); сам анонс не меняется. Выключается `ANNOUNCE_END=false`.
- **Перезапуск**: если перезагрузить сервис посреди эфира, повторного анонса не будет.

## Как выглядят сообщения

**Анонс** — фото (своё превью из лички или превью Twitch) с подписью:

```
Всем привет

🔴 <название стрима на Twitch>
🎮 <игра на Twitch>

<текст из /text>

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

**Окончание эфира** — отдельное текстовое сообщение:

```
⚫️ <название стрима на Twitch>
🎮 <игра на Twitch>

Эфир завершён, длился 2 ч 47 мин

Всем спасибо, кто забегал на стрим, повтор стрима можно посмотреть тут:

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

Название площадки — кликабельная ссылка. В анонсе — площадки, которые были в эфире в момент отправки, в итоге — все настроенные каналы. Строки 🎮 нет, если на Twitch не выбрана категория. Строки с текстом нет, если он не задан через `/text`.
