# stream-announce-bot

[English](README.en.md) · **Русский**

Бот следит за настроенными каналами на Twitch, YouTube и VK Live. Для каждого эфира он отправляет по одному анонсу на каждую выбранную площадку доставки (группу Telegram или канал Discord). Если вы ведёте эфир на нескольких площадках, например через OBS, ссылки на них можно собрать в одном сообщении. По окончании эфира бот может отправить отдельное сообщение с длительностью и ссылками на каналы, где можно найти записи.

Управлять ботом можно из окна приложения или командами в личке Telegram. Команд в Discord нет: он только принимает сообщения. Telegram необязателен, если задан вебхук Discord: тогда бот анонсирует только в Discord, а управление идёт через панель.

## Скачать и установить

Скачайте установщик со страницы [Releases](https://github.com/ToyTox/stream-announce-bot/releases) — собирать ничего не нужно.

**Mac**

1. Скачайте `stream-announce-<версия>-arm64.dmg` для Mac на Apple Silicon (M1 и новее) или `stream-announce-<версия>-x64.dmg` для Intel. Модель процессора указана в меню Apple () → «Об этом Mac».
2. Откройте `.dmg` и перетащите приложение в «Программы».
3. Приложение использует подпись ad hoc, поэтому macOS может заблокировать первый запуск. После попытки открыть приложение перейдите в «Системные настройки → Конфиденциальность и безопасность», прокрутите вниз до сообщения о приложении, нажмите «Всё равно открыть» и подтвердите запуск. [Инструкция Apple](https://support.apple.com/en-us/102445)

**Windows**

1. Скачайте `stream-announce-<версия>-x64.exe` и запустите. Установщик запросит права администратора и поставит приложение в `Program Files`; папку можно сменить. Ярлыки появятся на рабочем столе и в меню «Пуск».
2. SmartScreen может написать «Система Windows защитила ваш компьютер»: нажмите «Подробнее → Выполнить в любом случае».

При первом запуске окно откроется на вкладке «Настройки». Дальше приложение живёт в фоне: иконка в строке меню (на Windows — в трее) показывает статус, а окно открывается по пункту «Открыть панель». Закрытие окна крестиком бота не останавливает; чтобы выйти, выберите «Выйти» в меню иконки.

## Настройка бота

Во вкладке «Настройки» укажите хотя бы одну площадку доставки (Telegram или Discord) и хотя бы одну платформу для отслеживания эфира (Twitch, YouTube или VK Live). Подсказки «Как получить» есть в группах Telegram, Discord, Twitch, YouTube и VK Live.

### Площадки доставки

- **Telegram.** Напишите `@BotFather` команду `/newbot` и укажите полученный токен в `TELEGRAM_BOT_TOKEN`. Добавьте бота в группу и разрешите ему писать. Для доставки нужны токен и `TELEGRAM_CHAT_ID`. Если используете только Discord, оставьте оба поля пустыми.
- **Discord.** Откройте «Настройки сервера → Интеграции → Вебхуки → Новый вебхук», выберите канал и нажмите «Копировать URL вебхука». Укажите адрес вида `https://discord.com/api/webhooks/<id>/<токен>` в `DISCORD_WEBHOOK_URL`. Храните его в секрете.

**Как узнать `TELEGRAM_CHAT_ID`.** Если у супергруппы есть ссылка на сообщение вида `t.me/c/2241331974/…`, прибавьте `1000000000000` к первому числу после `t.me/c/` и поставьте знак минус. В примере получится `-1002241331974`. [Ссылки на сообщения](https://core.telegram.org/api/links#message-links) · [Формат ID](https://core.telegram.org/api/bots/ids)

Для обычной группы или если ссылки `t.me/c/…` нет, получите ID через Telegram Bot API. Полностью завершите приложение через «Выйти» в меню иконки. Для этого способа у бота не должно быть активного webhook или другого запущенного клиента, который получает обновления с тем же токеном. Отправьте в целевую группу `/start@<имя_бота>`, подставив имя бота без угловых скобок. Telegram доставляет адресованную команду даже при включённом режиме приватности. [Как бот получает сообщения](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get)

Запустите подходящий блок и введите токен по запросу. Ввод скрыт. Токен не попадает в историю команд, а запрос `getUpdates` идёт по HTTPS напрямую к Telegram.

**macOS — Терминал**

```sh
(
  printf 'Bot token: '
  IFS= read -r -s telegram_bot_token || exit 1
  printf '\n'
  printf 'url = "https://api.telegram.org/bot%s/getUpdates"\n' "$telegram_bot_token" |
    curl --disable --silent --show-error --config -
)
```

**Windows — PowerShell**

```powershell
& {
  $telegramBotToken = [pscredential]::new('bot', (Read-Host 'Bot token' -AsSecureString)).GetNetworkCredential().Password
  ('url = "https://api.telegram.org/bot{0}/getUpdates"' -f $telegramBotToken) |
    curl.exe --disable --silent --show-error --config -
}
```

В массиве `result` найдите только что отправленную команду по `message.text`, времени отправки `message.date` (Unix-время в секундах) и названию группы `message.chat.title`. Снова откройте приложение и скопируйте `message.chat.id` целиком, со знаком минус и всеми цифрами, в `TELEGRAM_CHAT_ID`. Запрос читает неподтверждённые обновления с действующим фильтром Telegram, который у этого приложения включает `message`. Если ответ содержит 100 более ранних обновлений, дождитесь их истечения и отправьте команду ещё раз. [Метод getUpdates](https://core.telegram.org/bots/api#getupdates)

### Платформы для отслеживания

- **Twitch.** Заполните все три поля `TWITCH_LOGIN`, `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET` или оставьте весь блок пустым. Логин возьмите из `twitch.tv/<логин>`. Client ID и Client Secret выдаются при создании приложения с Redirect URL `https://localhost` и типом клиента «Конфиденциально». [Консоль Twitch](https://dev.twitch.tv/console/apps)
- **YouTube.** Укажите ID канала вида `UC…` в `YOUTUBE_CHANNEL_ID`. [Как найти ID канала](https://support.google.com/youtube/answer/3250431?hl=ru)
- **VK Live.** Укажите в `VKVIDEO_CHANNEL` имя канала из `live.vkvideo.ru/<имя>`.

### Необязательные поля

- `TELEGRAM_TOPIC_ID` направляет сообщения в отдельную тему. Скопируйте ссылку на сообщение из нужной темы. Если в ссылке есть параметр `thread`, возьмите его значение (`42` в `t.me/c/2241331974/357?thread=42`). Если тема указана отдельным сегментом пути, возьмите число перед ID сообщения (`42` в `t.me/c/2241331974/42/357`). В обоих примерах `357` — ID сообщения. Для основной темы (General) оставьте поле пустым. [Форматы ссылок Telegram](https://core.telegram.org/api/links#message-links)
- `TELEGRAM_ADMIN_ID` нужен для команд и работы с ботом в личке, включая загрузку превью. Для доставки в группу достаточно токена и ID группы. Чтобы включить личку, узнайте свой ID у `@userinfobot`, укажите его в настройках и отправьте своему боту `/start`.
- С `YOUTUBE_API_KEY` бот делает один вызов `search.list` за проверку. Стандартной квоты в 100 вызовов в сутки при интервале в одну минуту хватает примерно на 100 минут. При исчерпании квоты панель показывает ошибки проверки YouTube, а бот продолжает обращаться к API. Для непрерывного опроса с настройками по умолчанию оставьте поле пустым, если квота не увеличена. Тогда бот читает страницу канала `/live`. [Квоты YouTube Data API](https://developers.google.com/youtube/data/determine_quota_cost)
- `VKVIDEO_REPLAY_URL` добавляет ссылку на канал с записями на `vkvideo.ru`. Подробнее о том, когда она появляется, см. [«Как выглядят сообщения»](#как-выглядят-сообщения).

После сохранения настроек откройте «Статус» и нажмите «Проверка связи». Панель отправит тестовое сообщение в каждое настроенное место доставки и покажет результаты по отдельности.

## Панель управления

| Вкладка | Что там |
|---------|---------|
| Статус | Текущий эфир, доставка анонса, состояние площадок и ошибки проверки. Ссылка «открыть в Telegram» появляется для текущего эфира после отправки анонса в супергруппу Telegram. Кнопки «Проверить сейчас», «Проверка связи», «Тестовый анонс в Telegram» и «Тестовый анонс в Discord». Кнопка тестового анонса видна для каждой настроенной площадки доставки |
| Сообщение | Текст для анонса (как `/text`), список ссылок с отметкой «Всегда в анонсе», загрузка своей картинки и предпросмотр анонса и итога эфира |
| Настройки | Форма настроек бота. Секреты замаскированы, пустое поле сохраняет прежний секрет. Сохранение проверяет значения и перезапускает бота без повторного анонса. «Импортировать .env…» проверяет выбранный файл и при успехе целиком заменяет текущий `.env` |
| Лог | Последние 300 строк того, что бот пишет |

- Панель доступна только на компьютере с ботом, пароль для неё не нужен.
- «Проверка связи» и обе кнопки тестового анонса отправляют реальные сообщения даже при `DRY_RUN`. Тестовый анонс с пометкой «🧪 Тест» уходит только в выбранную площадку доставки, в Telegram — без звука.
- Панель хранит загруженную картинку в папке данных рядом с базой. Если настроены Telegram и `TELEGRAM_ADMIN_ID`, бот при загрузке также отправляет её вам в личку, чтобы получить `file_id`. Если Telegram настроен без ID администратора, картинка отправляется в группу файлом. Текст и картинку для анонса можно задать в панели при любой настроенной доставке.
- Если из-за ошибки в настройках бот не запустился, панель покажет причину. Исправьте её во вкладке «Настройки».

### Устройства и удалённый API

Тег `v0.4.0` включает локальный `/api/v1`. Вкладка «Устройства», сопряжение по QR и удалённый доступ через Tailscale появились в ветке после этого тега. С телефона можно обращаться к API обычным HTTP-клиентом. Нативное приложение пока на этапе планирования. [План мобильного приложения](docs/mobile-app-plan.md)

Удалённый API выключен по умолчанию. Подключите компьютер и телефон к одной сети Tailscale, задайте `REMOTE_ENABLED=true` в `.env` и полностью перезапустите приложение (выберите «Выйти» в меню иконки, затем запустите снова). Настольное приложение читает `.env` из папки данных, CLI — из рабочей папки. Tailscale шифрует HTTP-трафик между устройствами. [Шифрование Tailscale](https://tailscale.com/docs/concepts/tailscale-encryption)

Во вкладке «Устройства» нажмите «Подключить телефон». Панель показывает QR с одноразовым кодом, когда удалённый API работает на подтверждённом адресе Tailscale. Там же видны имена устройств, даты подключения, последнее использование и состояние. Кнопка «Отключить» отзывает токен устройства. Список и отзыв доступны даже при остановленном боте.

[Диагностика и проверка с телефона](docs/development.md#удалённый-доступ-через-tailscale) · [Спецификация API v1](docs/api-v1.yaml)

## Команды бота

Пишите боту в личку. Он отвечает только на сообщения от `TELEGRAM_ADMIN_ID`; без этой настройки команды выключены.

| Команда | Описание |
|---------|----------|
| `/text <текст>` | Текст в ближайший анонс; после отправки сбрасывается |
| `/text` | Показать текущий текст |
| `/text -` | Сбросить текст |
| *фото* | Своё превью для всех анонсов — до замены другим фото или сброса. Отправлять как фото, со сжатием |
| `/image` | Задано ли своё превью |
| `/image -` или `/image_clear` | Сбросить своё превью |
| `/status` | Идёт ли эфир, на каких площадках и с какого времени |
| `/help` | Справка по командам |

## Язык

Интерфейс и тексты анонсов бывают на русском и английском, настраиваются отдельно. Язык интерфейса переключается в шапке панели или полем «Язык интерфейса» во вкладке «Настройки»; язык анонса — полем «Язык текстов анонса» там же. Если оставить пустыми, интерфейс выберется по языку системы, а анонс будет на языке интерфейса. Команды бота на всех языках одинаковые.

## Как выглядят сообщения

**Анонс** в Telegram выглядит так. Если есть картинка, текст становится подписью к ней.

```
Всем привет

🔴 <название стрима на приоритетной площадке>
🎮 <игра или категория>

<текст из /text или панели>

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

**Окончание эфира** приходит отдельным текстовым сообщением.

```
⚫️ <название стрима на приоритетной площадке>
🎮 <игра или категория>

Эфир завершён, длился 2 ч 47 мин

Всем спасибо, кто забегал на стрим, повтор стрима можно посмотреть тут:

▶️ Twitch
▶️ YouTube
▶️ VK Video
▶️ VK Live
```

- **Название и игра.** В поле «Название, игра и превью берутся с» (`PRIMARY_PLATFORM`) можно выбрать приоритетную площадку. По умолчанию это Twitch. Если бот не обнаружил текущий эфир на этой площадке, он подставляет заголовок «Трансляция». Строки с игрой и вашим текстом появляются, когда для них есть данные.
- **Картинка.** В обоих каналах доставки бот в первую очередь использует своё загруженное превью. Без него Telegram берёт доступное превью приоритетной площадки, а Discord берёт превью только с Twitch, когда Twitch выбран приоритетным. Если подходящей картинки нет, Telegram отправляет текст, а Discord — карточку без изображения.
- **Ссылки в анонсе.** Обычно бот подставляет кликабельные ссылки на площадки, где идёт эфир в момент отправки. Если во вкладке «Сообщение» есть ссылки с отметкой «Всегда в анонсе», бот ставит только их в порядке списка. Можно добавить и площадки, которые бот не отслеживает. Чтобы сохранить список, отмеченные ссылки должны помещаться в отведённую часть подписи Telegram (около 700 символов с разметкой).
- **Пауза перед анонсом.** Обычно бот ждёт `ANNOUNCE_GRACE_MS` после обнаружения первой площадки (по умолчанию 90 секунд). С отмеченными ссылками он может отправить анонс раньше, как только увидит эфир на приоритетной площадке. Если она не появилась, действует обычная пауза.
- **Итог эфира.** Если включено `ANNOUNCE_END` (по умолчанию да), бот отправляет итог только туда, куда дошёл анонс. Для этого все отслеживаемые площадки должны подтвердить, что эфир завершён, а с последнего обнаружения эфира должна пройти пауза `OFFLINE_GRACE_MS` (по умолчанию 3 минуты). В итог входят ссылки на настроенные каналы независимо от отметок «Всегда в анонсе».
- **VK Video.** Если задан `VKVIDEO_REPLAY_URL`, обычный анонс включает эту ссылку рядом с VK Live, когда там идёт эфир. В итог она добавляется, если настроен канал VK Live.

Подробные правила — в [документе для разработчиков](docs/development.md).

## Обновление и данные

При запуске и затем раз в сутки приложение проверяет обновления на GitHub. Если доступна новая версия, в меню иконки появляется «Доступна версия X — скачать». Установите новую версию поверх прежней, чтобы сохранить настройки и базу. Текущая версия видна в меню иконки и в шапке панели.

Данные лежат в `~/Library/Application Support/Анонсы стримов/` на Mac и `%APPDATA%\Анонсы стримов\` на Windows: файлы `.env` и `bot.db`. На Windows они хранятся отдельно для каждого пользователя, поэтому запускайте бота под одной учётной записью.

**Запускайте бота только в одном месте — на Mac или на Windows.** Две копии отправят анонс дважды (в Telegram с одним токеном и в Discord с одним вебхуком), а с Telegram ещё и будут перехватывать друг у друга команды.
