# Аудиты глав

Здесь лежат отчёты аудита глав A, B и C из `docs/mobile-app-plan.md`: один файл на главу, `chapter-A.md`, `chapter-B.md`, `chapter-C.md`. Их пишет агент `chapter-auditor` через `scripts/chapter-audit.mjs`. Наличие файла означает, что аудит главы уже был. Описание запуска — в разделе «Аудит глав» в `docs/development.md`.
